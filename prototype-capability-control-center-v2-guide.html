Purpose & scope

This prototype explores how Products & Solutions could evolve beyond classic download/install fulfillment while preserving the 2021 field-guide guardrails: help users get to their product faster, keep subscription/administration on adjacent Account surfaces, and avoid turning P&S into a marketplace junk drawer.

V2 specifically tests:

  • A unified catalog of Autodesk products and org-deployed marketplace solutions
  • Org-approved discovery and workflow-aware recommendations
  • Admin operator tools (seat summary, user management, billing hub) vs. a simplified user workspace
  • Product-contextual cross-sell (e.g. AutoCAD ↔ Plot Publisher solutions)

Products & Solutions tabs

My products & solutions (default)

The landing view. Three catalog sections:

  • From Autodesk — core products (AutoCAD, Revit, Fusion, Inventor) with install/download CTAs
  • From Marketplace — deployed apps, agents, skills, templates; filterable by type
  • Custom integrations — customer-built connectors; View details link only (no detail page by design)

Also includes Workflow recommendations (contextual discovery) at the bottom of the tab.

Org-approved solutions

Curated grid/carousel of solutions approved for the org. Admin CTAs use Buy. Undeployed items open a marketplace listing detail page. Already-deployed items open the app management detail page (same as My products).

Below the grid: Explore more solutions from the Marketplace — purple divider section for net-new discovery with Request approval CTAs.

Other tabs (Product updates, Custom install, …)

Placeholder tabs preserved for IA parity with production Account. Content not built in this prototype.

Key features & rationales

Management summary cards

On product and deployed-solution detail pages, three cards summarize operational status at a glance:

  • Updates — installed vs latest version; answers “does my team need a patch?”
  • Subscription — seats, term, expiry; links out to billing (admin job stays on Billing & orders)
  • User assignment — seat utilization bar (admin only); assign-users table/modal intentionally removed from solution pages in V2

Rationale: Admins need a control-panel read without leaving fulfillment context; users only need update status for their own install workflow.

Org-approved solutions + Explore more

Separates approved-for-org solutions (buy/deploy) from net-new marketplace discovery (request approval). Purple marketplace divider visually distinguishes ecosystem discovery from the org catalog panel.

Rationale: Avoids collapsing “what we already approved” with “what we might approve” — different jobs, different trust signals.

Workflow recommendations

Cards surfaced on My products based on demo org context (AEC, BIM Manager, owned products). Each links to a listing detail page.

Rationale: Tests Phase 1 vision for contextual discovery beyond static grid sort — without replacing the catalog.

AutoCAD cross-sell sections

On AutoCAD and AutoCAD-adjacent solution pages: Your AutoCAD solutions (owned/assigned) and Discover more solutions for AutoCAD (org-approved or request flows).

Rationale: Product-contextual ecosystem access — extensions that help a specific product work better, not account-wide marketplace browse.

Custom integrations

Cards show in catalog; Add custom integration opens a step-1 flow stub. View details shows a toast — no detail page.

Rationale: Signals admin-led connector setup without implying full fulfillment detail parity with marketplace apps.

Billing and orders (Subscription Hub VisD)

Admin-only full page: upcoming modules, subscription summary cards (including marketplace apps), subscriptions/contracts table. Subscription row drill-down arrows removed — list view only in prototype.

Rationale: Billing is an adjacent Account job (field guide off-surface for seat/subscription admin on P&S); prototype shows the handoff surface, not deep subscription detail pages.

Suggested click paths

Use these paths in reviews or stakeholder walkthroughs:

  1. Admin fulfillment: Admin view → AutoCAD → summary cards → downloads → Your AutoCAD solutions carousel → another solution
  2. Admin ecosystem: Org-approved tab → Plot Publisher (Buy listing) vs Model Checker (deployed app detail) → Explore more → Request approval
  3. Admin operations: User Management → any user → assigned products → back → Billing and orders → Subscriptions tab
  4. User workspace: User view → DWG Markup Sync → updates card only → download section
  5. Discovery: My products → Workflow recommendations → listing detail → back

Known limits (intentional)

  • Most CTAs show toasts — no real commerce, assignment, or install flows
  • Data is representative demo content, not live entitlements
  • Custom integrations and user billing pages are deliberately shallow
  • Secondary P&S tabs and most Billing tabs are placeholders
  • Assign-users section removed from solution detail pages; summary card remains for admin
